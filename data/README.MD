# Data files

These files are from William Whitaker's WORDS, obtained from
https://github.com/mk270/whitakers-words at commit 9b11477.

- `INFLECTS.LAT` — all Latin inflectional endings
- `DICTLINE.GEN` — ~39,000 dictionary entries
- `ADDONS.LAT` — prefixes, suffixes, enclitics
- `UNIQUES.LAT` — irregular whole-word entries

Whitaker released WORDS and its data into the public domain.
