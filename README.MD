### Whitaker Words C++

This is a C++ toy implementation of William Whitaker's WORDS, a Latin-English dictionary with inflectional morphology support, heavily derived from this [repo](https://github.com/mk270/whitakers-words/).
The purpose of this implementation is to have it run in an embedded context, primarily on the ESP32 architecture.
